## Local preview

Run `python3 -m http.server 8774` in this directory and open http://localhost:8774/.

## Publishing

GitHub Pages serves the root of the `main` branch. HTML, CSS, JavaScript, fonts and imagery are self-contained; no build step is required.

This is an independent design prototype, not the official SoundOn service. Artwork and brand assets belong to their respective owners. Analytics and audience figures shown in interactive demos are illustrative.
