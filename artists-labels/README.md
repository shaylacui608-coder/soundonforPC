# SoundOn Artists / Labels

Unified homepage prototype with an Artists / Labels switch, glass sphere hero, release preparation interaction, reports, pricing and scrolling artist stories.

Published at https://shaylacui608-coder.github.io/soundonforPC/artists-labels/

Use `?audience=artists` or `?audience=labels` to open a specific mode.

Static HTML, CSS and JavaScript; no build required. Serve this directory with a local HTTP server to preview.

This is an independent design prototype, not the official SoundOn service. Artwork and brand assets belong to their respective owners. Report figures are illustrative, not actual artist earnings.
